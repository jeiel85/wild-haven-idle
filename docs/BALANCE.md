## 2. 생산 공식

```text
초당 보호 포인트 생산량 = 보호구역 기본 생산량 + 구조 동물 회복 보너스 합계
```

```text
보호구역 기본 생산량 = 보호구역 레벨 × 1.0 carePoint/sec
```

```text
동물 보너스 = 기본 보너스 × 회복 단계^1.15
```

도감 보너스:

```text
보호 중 동물 1종당 전체 생산량 +2%
```

최종 생산량:

```text
최종 생산량 = (보호구역 생산량 + 동물 보너스 합계) × 도감 보너스 배율
```

---

## 3. 오프라인 보상

```text
오프라인 시간 초 = 현재 시각 - 마지막 저장 시각
보상 = 초당 생산량 × 오프라인 시간 초
최대 인정 시간 = 8시간
```

시간 조작 대응:

- 현재 시각이 마지막 저장 시각보다 작거나 같으면 보상은 0
- 오프라인 시간은 최대 8시간까지만 인정
- MVP에서는 서버 시간을 사용하지 않음

---

## 4. 회복 지원 비용

```text
회복 지원 비용 = 기본 비용 × 현재 회복 단계^1.45
```

기본 비용:

| 희귀도 | 기본 비용 |
|---|---:|
| COMMON | 100 |
| UNCOMMON | 250 |
| RARE | 700 |
| EPIC | 2000 |
| LEGENDARY | 7000 |

MVP에서는 COMMON, UNCOMMON, RARE만 사용한다.

---

## 5. 보호구역 업그레이드 비용

```text
보호구역 업그레이드 비용 = 200 × 현재 레벨^1.6
```

보호구역 기본 생산량:

| 레벨 | 생산량 |
|---:|---:|
| 1 | 1/sec |
| 2 | 2/sec |
| 3 | 3/sec |
| 10 | 10/sec |

## 7. 초반 플레이 목표

| 플레이 시간 | 목표 경험 |
|---|---|
| 첫 1분 | 보호 포인트 증가 이해, 숲토끼 확인 |
| 첫 5분 | 첫 회복 지원, 보호구역 개선 조건 확인 |
