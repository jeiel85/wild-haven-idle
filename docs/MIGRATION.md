# Wild Haven Idle 마이그레이션 정책

## 1. 기본 원칙

사용자 데이터 구조를 변경할 때는 데이터 손실 가능성을 최우선으로 검토한다.

MVP에서는 DataStore 기반 로컬 저장을 사용한다. 저장 구조 변경 시 마이그레이션 계획 없이 진행하지 않는다.

---

## 2. 마이그레이션이 필요한 변경

아래 변경은 마이그레이션 계획 없이 진행하지 않는다.

- 저장 파일 형식 변경
- 설정 키 이름 변경
- GameState 구조 변경
- 동물 ID 변경
- 회복 단계 구조 변경
- 보호구역 레벨 구조 변경
- 사용자 생성 데이터 삭제 또는 재생성
- 앱 버전 간 호환성에 영향을 주는 변경

---

## 3. 기록 형식

마이그레이션이 필요한 경우 아래 내용을 기록한다.

```text
변경 전 구조:
변경 후 구조:
마이그레이션 방법:
실패 시 동작:
롤백 가능 여부:
검증 방법:
```

---

## 4. MVP 정책

MVP 단계에서는 가능하면 저장 구조를 단순하게 유지한다.

초기 릴리즈 전에는 저장 구조 변경이 가능하지만, 공개 배포 이후에는 반드시 마이그레이션을 고려한다.
