# Play Console Current Assets

이 폴더는 Google Play Console 스토어 등록정보에 바로 올릴 현재 그래픽 묶음입니다.

| 파일 | Play Console 위치 | 사양 |
|---|---|---|
| `icon-512.png` | 스토어 등록정보 -> 그래픽 -> 앱 아이콘 | 512x512 PNG, 16.8 KB |
| `feature-graphic-1024x500.png` | 스토어 등록정보 -> 그래픽 -> 기능 그래픽 | 1024x500 PNG, 80.9 KB |
| `phone-screenshots/*.png` | 스토어 등록정보 -> 그래픽 -> 휴대전화 스크린샷 | 1080x2340 PNG, 6장 |

스크린샷은 `store-graphics/v0.6.2-device-shots/`의 실기기 캡처를 업로드 순서에 맞춰 복사한 것입니다.
경량화된 앱 아이콘 원본은 `docs/assets/wild-haven-icon-source.png`이며, `icon-512.png`와 기능 그래픽은 이 원본에서 재생성했습니다.
